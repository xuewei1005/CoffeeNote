# CoffeeNote · 咖啡风味笔记

记录每一杯咖啡的最佳参数。  /  Keep the best recipe for every coffee.

**[English / English 完整介绍](README_EN.md)** · **[下载 APK / Download APK](https://github.com/xuewei1005/CoffeeNote/releases/latest)** · **[更新日志 / Changelog](CHANGELOG.md)**

CoffeeNote 是一款面向家庭咖啡爱好者的 Android 咖啡记录工具，管理咖啡豆、风味、养豆状态、冲煮参数和器具。
CoffeeNote is an Android coffee journal for home brewers, keeping beans, flavor notes, resting status, recipes and gear together.

本仓库只发布 APK、宣传视频、双语介绍和示例截图，不提供 App 源代码，也不授予开源许可。
This repository distributes APK releases, a promotional video, bilingual documentation and example screenshots only. The application source code is not published and no open-source license is granted.

## 功能 / Features

| 功能 / Feature | 中文说明 / Chinese | English |
| --- | --- | --- |
| 我的豆仓 / Coffee shelf | 品牌、豆名、多产地、处理法、烘焙度、日期和完整风味。 | Brand, name, multiple origins, processing, roast, dates and tasting notes. |
| 豆袋 OCR / Bag recognition | 本地识别并自动归类中日韩英文字段。 | On-device recognition and field classification for Chinese, Japanese, Korean and Latin text. |
| 冲煮配方 / Brewing recipes | 意式、手冲、冰手冲三个固定单选标签，参数独立；意式默认 25 秒。 | Three single-select tabs with independent recipes; espresso defaults to 25 seconds. |
| 养豆状态 / Resting status | 按烘焙日、养豆天数和开封日自动计算。 | Calculated from roast date, rest days and opened date. |
| 卡片、器具与备份 / Cards, gear and backup | 长按排序或删除，管理器具，JSON 导出导入换机。 | Reorder or delete cards, manage gear, and export or import JSON for device transfer. |
| 主题与语言 / Themes and languages | 浅色、深色、跟随系统；中日韩英。 | Light, dark or system theme; Chinese, Japanese, Korean and English. |
